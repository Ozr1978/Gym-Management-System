# Gym Management System

A frontend gym management system built from scratch using HTML, CSS, and JavaScript.

## Features

- Role-based access control
  - Owner
  - Coach
  - Staff
- Member management
- Subscription management
- Class scheduling
- Class capacity management
- Member bookings
- Search functionality
- Waiting lists
- Dashboard with upcoming classes
- Dynamic UI based on user role
- LocalStorage for persistent data
- SessionStorage for the current session

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage
- SessionStorage

## User Roles

### Owner
Full access to the system, including managing members, employees, classes, and permissions.

### Coach
Can view all classes but can only manage classes assigned to them.

### Staff
Can manage members, subscriptions, and bookings, but cannot manage employees or permanently delete members.

## Purpose

This project was built as a self-directed JavaScript project to practice DOM manipulation, events, data management, array methods, objects, and application logic in a real-world scenario.

## Note

This is a frontend-only learning project. Authentication and stored data are not suitable for production use.
